{%- comment -%} Link a una risorsa. Parametri: url, label, class. - url vuoto -> solo testo (nessun link) - url con "://" -> link esterno, nuova scheda - url con "/assets/" -> file del sito (pdf, immagini, pagine statiche), nuova scheda - altro (es. /informatica/...) -> pagina del sito, stessa scheda I percorsi interni passano da relative_url, quindi funzionano anche con baseurl. {%- endcomment -%} {%- assign u = include.url | default: "" -%} {%- if u == "" -%} {{ include.label }} {%- elsif u contains "://" -%} {{ include.label }} {%- elsif u contains "/assets/" -%} {{ include.label }} {%- else -%} {{ include.label }} {%- endif -%}
